# Prompt — Criar AGENTS.md

Leia as fontes canônicas existentes do projeto.

Crie um `AGENTS.md` curto que funcione como entrypoint dos agentes.

Ele deve definir:

1. ordem de leitura das fontes;
2. autoridade de PRD, System Design, ADRs, Principles, Design, Slices, SPEC e PLAN;
3. regras operacionais essenciais;
4. como lidar com conflito relevante;
5. validações obrigatórias antes de declarar implementação concluída.

Não replique o conteúdo dos documentos. Apenas roteie o agente até eles.
