# Prompt — Criar ADRs

Leia PRD e `docs/architecture/SYSTEM-DESIGN.md`.

Identifique apenas decisões arquiteturais relevantes com alternativas e trade-offs reais. Para cada uma, crie um ADR em `docs/architecture/adr-XXX-<slug>.md`.

Cada ADR deve conter Context, Decision, Alternatives Considered, Positive/Negative Consequences e Related.

Não crie ADR para detalhes locais de implementação, preferências pessoais ou decisões já plenamente explicadas por outro ADR.

Ao final, verifique se o System Design e os ADRs formam uma arquitetura coerente.
