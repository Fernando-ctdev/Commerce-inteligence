# AGENTS.md

`AGENTS.md` é o entrypoint dos agentes no repositório.

Deve ser curto e dizer:

- quais fontes ler;
- qual a ordem de leitura;
- autoridade de cada fonte;
- regras operacionais essenciais;
- como tratar conflitos;
- validações obrigatórias antes de declarar conclusão.

Não copie todo PRD, System Design e Design para dentro dele. A função é rotear contexto.
