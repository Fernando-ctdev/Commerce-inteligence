# SDD por Slice

SDD acontece no slice atual.

## SPEC

Define comportamento, regras, estados, erros, UX relevante, critérios de aceite e fora de escopo.

## PLAN

Transforma a SPEC aprovada em execução incremental: arquivos, migrations, componentes, use cases, testes e ordem de trabalho.

Evite especificar antecipadamente todos os slices. O estado real do código deve informar a SPEC e o PLAN do próximo slice.
