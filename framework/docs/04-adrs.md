# ADRs

ADR registra uma decisão arquitetural relevante e seus trade-offs.

Crie ADR quando a decisão afeta arquitetura, boundaries, persistência, segurança, integração, contrato externo ou dependência transversal relevante.

Não crie ADR para detalhes locais de implementação.

Estrutura mínima: Contexto → Decisão → Alternativas → Consequências → Relações.
