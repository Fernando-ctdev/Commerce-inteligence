# Design System / UX/UI

`DESIGN.md` é a fonte de verdade de UX/UI.

Pode definir:

- princípios de UX;
- direção visual;
- responsividade;
- tokens de cor e tipografia;
- espaçamento/layout;
- componentes conceituais;
- estados;
- acessibilidade;
- comportamento mobile/desktop;
- motion quando relevante.

Não use o Design System para duplicar regras de backend ou ADRs.
