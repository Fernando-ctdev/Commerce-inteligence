# Deploy, Observabilidade e Evolução

Depois que os slices necessários estão concluídos, faça deploy com os gates apropriados ao projeto.

Observe falhas técnicas e comportamento real do produto. Feedback pode provocar:

- novo slice;
- alteração do PRD;
- mudança de Design;
- ajuste de System Design/ADR.

A evolução volta ao ponto mínimo necessário do framework e segue novamente pelo loop de entrega.
